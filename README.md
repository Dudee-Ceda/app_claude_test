# 🏗️ ออกแบบคานคอนกรีตเสริมเหล็ก (Streamlit)

เว็บแอปสำหรับวิเคราะห์และออกแบบคาน คสล. ช่วงเดียว ด้วยวิธีกำลัง (Strength Design Method)
ตามแนวทาง วสท. / ACI 318 ในหน่วย kg, cm, ksc

## ความสามารถ
- รูปแบบคาน: ช่วงเดียวธรรมดา, คานยื่น, ยึดแน่นสองปลาย, ยึดแน่น-หมุนได้
- น้ำหนักแผ่ DL/LL + น้ำหนักคานเอง + แรงจุดหลายตำแหน่ง (แก้ไขในตารางได้)
- การรวมน้ำหนัก 1.4D+1.7L หรือ 1.2D+1.6L
- แผนภาพแรงเฉือน โมเมนต์ดัด และการโก่งตัว (วิเคราะห์ด้วย Finite Element)
- ออกแบบเหล็กรับโมเมนต์บวก/ลบ รวมถึงคานเสริมเหล็กสองชั้น (Doubly Reinforced) และการวางเหล็ก 2 ชั้น
- ออกแบบเหล็กปลอกที่หน้าตัดวิกฤต (ระยะ d จากจุดรองรับ)
- ตรวจสอบการโก่งตัวด้วย Ie (Branson) รวมผลระยะยาว
- วาดรูปหน้าตัดพร้อมตำแหน่งเหล็กเสริม

## การติดตั้งและใช้งาน
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ทดสอบ
```bash
pip install pytest
python -m pytest
```

## โครงสร้างโปรเจกต์
```
app.py              # หน้าเว็บ Streamlit
beam/analysis.py    # วิเคราะห์แรงภายในและการโก่งตัว (FEM)
beam/design.py      # ออกแบบรับโมเมนต์ แรงเฉือน และการโก่งตัว
tests/test_beam.py  # ทดสอบเทียบกับสูตรมาตรฐาน
```

> ⚠️ ใช้เพื่อการศึกษาและการออกแบบเบื้องต้นเท่านั้น ผลการออกแบบจริงควรตรวจสอบโดยวิศวกรผู้มีใบอนุญาต
