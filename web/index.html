หลักการออกแบบ (Strength Design Method)

  • น้ำหนักบรรทุกประลัย wu = αD(SW + SDL) + αL·LL คิดต่อแถบกว้าง 1 m
  • Rn = Mu / (φ b d²), ρ = 0.85f'c/fy · [1 − √(1 − 2Rn/0.85f'c)]
  • As,min = ρtemp·b·h: 0.0020 (SR24, SD30), 0.0018 (SD40), 0.0018×4000/fy ≥ 0.0014 (fy > 4000)
  • ρ ≤ 0.75ρb, ρb = 0.85β₁f'c/fy · 6120/(6120 + fy)
  • ระยะห่างเหล็กหลัก ≤ 3h, เหล็กกันร้าว ≤ 5h และทุกตำแหน่ง ≤ 300 mm; ระยะห่างทุกตำแหน่งในแผ่นเดียวกันหารลงตัวกับระยะ Module 300, 250 หรือ 200 mm (เลือก Module ที่ใช้เหล็กน้อยที่สุด) เหล็กทุกชุดจึงตรงแนวกัน
  • แรงเฉือน φVc = φ·0.53√f'c·b·d

การแอ่นตัว (พื้นทางเดียว)

  • Ie = (Mcr/Ma)³Ig + [1 − (Mcr/Ma)³]Icr ≤ Ig, Mcr = fr·Ig/yt, fr = 2√f'c
  • Δ = wL⁴/(k·Ec·Ie); k = 384/5 ช่วงเดียว, 185 ต่อเนื่องปลายเดียว, 384 ต่อเนื่องสองปลาย, 8 พื้นยื่น (+ PL³/3EI)
  • λ = ξ/(1 + 50ρ'); ตรวจ ΔL ≤ L/360 และ λΔD + ΔL ≤ L/240 (พื้นยื่นใช้ 2L)
  • ถ้า h < h,min แต่การแอ่นตัวผ่านเกณฑ์ ถือว่าใช้ได้ (ACI 9.5.2)

พื้นสองทาง: ACI 318-63 Method 2

  • m = S/L ≥ 0.5, M = C·wu·S² (แถบกลาง); แถบเสาใช้ 2/3 ของแถบกลาง
  • C ตาม Case 1–5 (จำนวนขอบไม่ต่อเนื่อง) เทียบบัญญัติไตรยางศ์ตาม m; ช่วงยาวใช้ C ที่ m = 1.0
  • ความหนาต่ำสุด ≥ เส้นรอบรูป/180 และ ≥ 9 cm; เหล็กช่วงยาววางชั้นใน dL = dS − db
  • น้ำหนักลงคาน: ด้านสั้น wS/3, ด้านยาว wS/3 · (3 − m²)/2

ปริมาณวัสดุ (BOQ)

  • เหล็กล่างยาวเต็มช่วง + ฝัง 0.10 m แต่ละปลาย; เหล็กบนยาว L1 = Ln/4 (ขอบไม่ต่อเนื่อง) หรือ L2 = Ln/3 (ที่รองรับต่อเนื่อง) + 0.15 m; Type B/D/F มีเหล็กบนตลอดช่วง
  • เหล็กบนพื้นยื่นยาว 2L; น้ำหนักเหล็ก 0.785 kg/m ต่อพื้นที่ 1 cm²
